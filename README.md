# 🎓 School Management Website

## 📌 Project Overview
This project is a web-based platform designed to manage and display school content in a structured and user-friendly way.

It focuses on organizing school data such as news, educational resources, and student information, with a simple content management system for teachers.

---

## ⚙️ Core Features

### 🏠 Home Page
- Displays latest school news (last 5 updates)
- Quick navigation links
- Clean and simple UI

### 📰 News System
Teachers can:
- Add news
- Delete news
- Dynamic content display

### 👨‍🏫 Teacher Dashboard
Each teacher has a dedicated account (username & password)

Permissions:
- Create news
- Delete news

### 📚 Educational Resources
- Organized resources for different grades
- Easy access structure

### 🏆 Top Students
- Display top students for each grade
- Structured data presentation

### 📞 Contact & Support
- External links integration (Facebook / LinkedIn)
## 🤖 AI Chatbot

* 💬 Interactive chatbot for the school website
* 🤖 AI-powered assistance for students and visitors
* 📚 Helps users get information about the school
* ⚡ Fast and easy interaction
* 📱 Responsive chat interface

---

## 🧠 Technical Highlights
- Built as a structured multi-page web system
- Role-based access for teachers
- Dynamic content handling using backend logic
- Focus on scalability and maintainability

---

## 🛠️ Tech Stack
- Frontend: HTML, CSS  
- Backend: Python (Flask)  
- Database: SQLite  

---

## 🚀 Future Improvements
- Authentication system (secure login system with roles)
- Admin dashboard for full control
- Student Results System:
  - Students can enter their exam seat number
  - System displays their result instantly
  - Secure and structured results database
- Improve UI/UX design
- API integration for scalability
